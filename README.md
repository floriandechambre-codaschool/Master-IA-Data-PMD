# PMD — Préparation et manipulation de données

Travaux pratiques du module : exploration, nettoyage, transformation et modélisation de données de ventes avec Python (NumPy, pandas, scikit-learn).
Les notebooks sont numérotés par séance (`01_…` à `06_…`) et s'exécutent dans l'ordre. Python 3.12 recommandé.

## Installation

1. Créer l'environnement virtuel : `python -m venv .venv`
2. L'activer : `.venv\Scripts\activate` (Windows) ou `source .venv/bin/activate` (macOS/Linux)
3. Installer les dépendances : `pip install -r requirements.txt`
4. Placer les fichiers sources dans `data/raw/` (non versionné, en lecture seule) ; les résultats sont écrits dans `data/processed/`
5. Lancer `jupyter lab` et ouvrir le premier notebook
